# GloSkin TikTok Script Prompt

Write a TikTok script for GloSkin.

Required markdown sections, exactly in this order:

HOOK
BEATS
CTA
SHOTLIST

Rules:
- HOOK is one short spoken line.
- BEATS is a numbered list.
- The CTA section must contain only the literal token <<CTA>>; never write CTA text or a URL.
- In spoken dialogue and voice-over, spell the brand "Glow Skin" so TTS uses
  the intended long-o pronunciation. Keep the written brand "GloSkin" in
  metadata, labels, and visible app copy.
- SHOTLIST should use app screenshots, selfies, product labels, and simple text
  overlays.
- Voice is punchy and skincare-native, not clinical.
- Keep claims cosmetic/educational. No cure/treat/prevent language.
- Describe product scores as profile-fit guidance based on the user's scan or
  entry quiz. Never call a score proof that a product is safe, effective, or
  guaranteed to work.
- Keep each spoken app-demo beat short enough for relaxed delivery. Avoid
  repeating the same noun in adjacent lines when a simpler phrase works.
- When a shot changes from a physical product to an app screen, specify a clean
  hard cut with each object absent from the other shot. Never prompt an
  object-to-phone morph or continuous transformation.

Return only the script markdown.
